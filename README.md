# 🌾 农业信息化管理系统 - 毕业设计项目

## 📋 项目简介
基于Flask + SQLite的轻量级农业监控系统，实现农田环境数据的实时采集、可视化展示和智能报警功能。

## ✨ 核心功能
- ✅ 实时环境监控（温湿度、土壤墒情、光照）
- ✅ 数据图表可视化
- ✅ 阈值报警通知
- ✅ 设备在线管理
- ✅ 多角色用户系统

## 🚀 快速开始
```bash
# 克隆项目
git clone https://github.com/你的用户名/super-system.git

# 安装依赖
pip install -r requirements.txt

# 运行系统
python app.py
